# Известные проблемы (KNOWN ISSUES)

## Карантин: test/integration/app_flow_test.dart (M5, аудит 4.2)

Два теста помечены `skip:`:

- `app should start and show loading state`
- `app should handle basic lifecycle`

**Причина:** оба вызывают `app.main()` — полную загрузку приложения с
инициализацией Hive, DI-контейнера, Supabase-клиента и плагинов. Это
интеграционные тесты, рассчитанные на запуск на эмуляторе/устройстве
(`integration_test` binding); в headless-окружении `flutter test` они падают
на этапе инициализации — без связи с логикой синхронизации или фото-подсистемы.

**Подтверждено предсуществующим:** падали на чистом HEAD до начала работ
над sync/фото (этапы 2–4).

**Как снять карантин:** запускать эти тесты на реальном устройстве/эмуляторе
(`flutter test integration_test/` после переноса файла туда) либо
переписать на фейковое окружение DI — отдельная задача.
