# ПРАВИЛА ПРОЕКТА (для любого ИИ-ассистента)

- Одна задача = один промт = один коммит; у каждого шага критерии готовности и доказательства.
- Стоп после каждого шага: следующий шаг только после отчёта и команды владельца.
- UI заморожен (мобильный и настольный): любое визуальное изменение — только скриншоты «до/после» + согласие владельца.
- Ноль потерь: ничего не удаляем без архива; полнота доказывается счётчиками в реестрах.
- Миграции данных: автоматический бэкап + возможность отката + отчёт.
- Один постоянный ключ подписи релизов; его резервная копия у владельца.
- Ключи и секреты — только в локальном скрытом конфиге (в .gitignore), никогда в коде и в репозитории.
- Реестры (решений, функций, различий платформ, мусора) обновляются при каждом изменении.
- Все документы на русском языке.
