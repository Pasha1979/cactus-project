## Ключевые решения (подробно в `_extracted/decisions.md`)

- **Offline-First + Event-Driven**, облако опционально (D-1)
- **Hive** + PlantIndexManager (вторичные индексы status/category/displayId, O(1)) (D-2, D-12)
- **Repository pattern** + **get_it** ручной DI (D-3, D-4)
- **8 провайдеров** вместо PlantProvider 2230 строк: PlantCrud, Watering, Wintering, Photo, Batch, Sync, QrCode, Weather (D-5); фасады для совместимости
- **go_router** + deep links `cactusapp://` (D-6); redirect различает launch/deep link (L-30)
- **UiState** sealed (D-7), **feature_flags** (D-9), **AppLogger** вместо print (D-15)
- **Синхронизация**: SyncManager, merge по permanentId + lastModified, local-wins для отсутствующих в облаке, дедуп фото (D-11, D-19). КРИТИЧНО: не упрощать merge (L-15)
