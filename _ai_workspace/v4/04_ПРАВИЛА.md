# 04 — ПРАВИЛА (выжимка; все R-1…R-36 — `_extracted/rules.md`)

## Железные (P0)
1. **Две платформы всегда**: изменение → Android + Windows; pubspec Windows перед копированием; различия сохранять. Гейт: `flutter analyze` чистый на ОБОИХ (R-4, R-5, R-17).
2. **Ноль потерь**: перед переносом/удалением — diff с оригиналом (`git show HEAD:`); sync/serialization/merge не упрощать (R-15, R-23, R-31).
3. **Обсуждать до реализации**: что, почему, файлы, риски, откат (R-2). Рискованное → Вариант А первым; не выбирать за пользователя (R-7).
4. **9 пунктов после КАЖДОГО шага**, автоматически (R-6): полнота·функции·различия·скрытые баги·запуск·связи·TODO·analyze·цели.
5. **Persistence-чек** (R-30): старт→загрузка·изменение→сохранение·перезапуск→восстановление. Release не чистит данные (R-25).
6. **Ноль потерянных уроков** (R-14): ошибка→урок; уроки читать ПЕРЕД шагом.
7. **Целостность плана** (R-13, R-12): после правки — проверка дублей/нумерации; задачи только в будущие шаги; TODO(N.N.N).
8. **Медленный режим** (R-18) в критич. зонах: провайдеры·миграции·роуты·тема·модели·синхронизация·фото.

## Рабочие
Простым языком (R-1) · 3 вероятных ошибки до кода + бэкап (R-8, R-16) · заглушки→`throw UnimplementedError` (R-11) · `DateTime.tryParse`+fallback (R-10) · `.withOpacity()`→`withValues` (R-26) · `print()`→AppLogger · маршрут=вызову, grep context.push (R-22) · >3 Consumer/>500 строк→подзадачи (R-27) · не к N+1 без подтверждения (R-21) · напоминать тесты обеих платформ (R-33) · доки не удалять, только `_archive/` (R-36).
